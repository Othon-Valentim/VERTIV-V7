# 🏗️ VERTIV Platform

**Viabilidade Estruturada com Rigor Técnico Imobiliário e Validação**

---

## 📋 Sobre o Projeto

A **VERTIV Platform** é uma solução SaaS de inteligência imobiliária que transforma a Metodologia TIV (Técnica Inteligente de Viabilidade) em uma plataforma web moderna com capacidades nativas de IA.

### Diferenciais

- ✅ Metodologia calibrada com 63 projetos reais (2016-2024)
- ✅ 16+ Skills TIV integradas com Claude AI
- ✅ Sistema de Gates numéricos com thresholds científicos
- ✅ Conformidade LGPD e CVM desde a concepção

---

## 🎯 Os 10 Passos TIV

| Passo | Nome | Descrição |

| P3 | Área de Influência | Polígono de mercado via isócronas |
| P4 | Vocação Imobiliária | Matriz de Atratividade |
| P5 | Legal e Zoneamento | Análise jurídico-urbanística |
| P6 | Demanda | Funil de 5 estágios |
| P7 | Oferta | Mapeamento VSO (3 tipologias) |
| P8 | Absorção | Velocidade de vendas (Fator 4:1) |
| P9 | Validação | Pesquisa de campo (44 questões) |
| P10 | FCD | Fluxo de Caixa Descontado (ROE) |
