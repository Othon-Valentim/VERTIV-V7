# Commit, Push e Pull Request

Execute as seguintes etapas em sequência:

1. **Git Status**: Verifique o estado atual do repositório
2. **Git Add**: Adicione todos os arquivos modificados ao staging
3. **Git Commit**: Crie um commit com mensagem descritiva seguindo o padrão:
   - Formato: "tipo: descrição breve"
   - Tipos: feat, fix, docs, refactor, test
4. **Git Push**: Envie as alterações para o repositório remoto
5. **Pull Request**: Crie um PR com:
   - Título claro e descritivo
   - Resumo das alterações
   - Checklist de testes

Antes de executar, pergunte ao usuário:
- Qual a descrição do commit?
- Qual branch de destino para o PR?
